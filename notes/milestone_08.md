## Reproduce

```sh
uv sync --locked
uv run --locked pytest -q
MPLCONFIGDIR=.cache/matplotlib uv run --locked python -m rrs.experiments.four_room_models
```

The command verifies the Milestone 7 input, constructs eight independent model
references, audits the four hallway models with 240,000 sampled rollouts, and
trains 30 sets of eight models for 200,000 transitions each. Outputs:

- [Model error curves](../figures/milestone_08_model_learning.png)
- [Final hallway-model predictions](../figures/milestone_08_option_models.png)
- `artifacts/four_room_models/learning.json`: per-seed error curves, exact model
  tables, reference identity checks, audit results, final mean predictions,
  acceptance checks and provenance.
- `artifacts/four_room_models/frozen_options.json.gz`: the precise policies and
  stopping rules, feature/state order, selected actor/critic weights and source
  hash. It includes all four primitive policies and four learned hallway options.
- `artifacts/four_room_models/models_step_{000000,010000,020000,030000,040000,200000}.json.gz`:
  full models for every training seed at six maturity levels.

The figures are tracked; JSON/gzip artifacts are ignored by git. Options
`--output-dir`, `--figures-dir` and `--option-snapshot` override paths. An absent
default option snapshot is regenerated with the unchanged Milestone 7 command.
A supplied missing path or existing corrupt input fails without replacement.
Acceptance failures raise after preserving the final report and figures.

The input snapshot's SHA-256 is pinned to the validated Milestone 7 artifact.
This deliberately rejects a different policy, including regeneration that differs
across software/hardware environments. Such a change needs a separately reviewed
input; it must not silently replace the options the models describe.

## Fixed options and experiment protocol

Use seed **7000** from Milestone 7 after its predeclared one-million-step training
budget. Freeze all four actual softmax policies and Equation 9 stopping rules.
The seed was predetermined, not selected by performance. All model-training
runs use this same set, so the reported uncertainty is conditional on those
policies rather than variation across option-training seeds.

Source: `artifacts/four_room_options/options_step_1000000.json.gz`, SHA-256
`2e800352b546604d862af4fa73ad9786e243b3b5f503a20a991e10580ff7ec40`, generated by
Milestone 7 code `e24dc66e5f9a490afd1fc3fe681c087478cbb827`.

The model order is UP, DOWN, LEFT, RIGHT, H1, H2, H3, H4. Model-training seeds are
8000–8029, independent of option training. Every uniform-behavior transition
updates all eight models with their own importance ratios and arrival-stopping
decisions. Only reaching the environment goal resets behavior, after learning
the terminal reward. There are 220–266 completed behavior episodes per run.

Use gamma=0.99, alpha_r=alpha_p=0.1, lambda=0, float32 parameters and zero initial
weights/traces. Measure every 1,000 transitions, including initialization.
The 200,000-step span and 30 runs follow the model-learning plot in the locally
saved paper's [Appendix A](https://arxiv.org/html/2202.03466v4#A1). Preserve the
10,000/20,000/30,000/40,000 checkpoints marked in that plot, plus zero and final
models, for subsequent planning comparisons. No seeds, learning rates, budgets
or acceptance thresholds changed after observing results.

The qualitative target is decreasing off-policy model error. These curves are
not claimed to match the paper numerically: our fixed option source and recorded
random streams are explicit project choices, and our successor metric retains
the full vector norm per source rather than averaging over output coordinates.

## Model semantics and independent references

The unchanged feature-facing TD/UWT update predicts expected discounted
environment reward and `gamma**K` times the final feature vector. It receives no
hallway bonus and no oracle values. Importance ratios use the requested action,
not the realized direction of stochastic movement. Goal arrival retains +1 but
has zero successor contribution. Every option executes at least one action,
even when its source is already a stopping state.

The existing oracle now supports both deterministic and stochastic environment
models, summing over action probabilities and environmental outcomes. It checks
that every state has a positive-probability stopping/termination path, rejects
improper options, and uses Python-double Bellman iteration. Only float32 policy
row roundoff within `1e-6` is normalized. The error certificate is the maximum
Bellman residual divided by `(1-gamma)`, with a required bound of `1e-10`.

Primitive models converge in one sweep and agree exactly with direct one-step
expected reward and discounted next-feature sums. Hallway references converge
in 184–244 sweeps; the largest error bound is `9.93095e-11`. For each hallway,
the independently evaluated Milestone 7 subtask value also agrees with
`R + N @ z / gamma`, with maximum discrepancy `7.42041e-10` over all states.
The division by gamma accounts for the subtask's `gamma**(K-1)` stopping bonus;
model successors retain Equation 15's `gamma**K` discount.

## Final accuracy

Errors below are means ± one standard error across 30 independently trained
models. Each run first computes RMSE over all 103 nonterminal source states.
Successor error uses the squared vector norm across all output features before
averaging sources; it is not divided by 103. Metric targets are float32 exports
of the independently certified Python-double reference models.

| Model | Reward RMSE | Successor RMSE | Reward / initial | Successor / initial |
| --- | ---: | ---: | ---: | ---: |
| UP | 0.088921 ± 0.003375 | 0.353666 ± 0.003353 | 27.32% | 50.84% |
| DOWN | 0.083499 ± 0.002309 | 0.349699 ± 0.002694 | 28.54% | 50.27% |
| LEFT | 0.093205 ± 0.002840 | 0.348977 ± 0.003707 | 30.80% | 50.17% |
| RIGHT | 0.096470 ± 0.002542 | 0.354482 ± 0.003731 | 32.86% | 50.74% |
| H1 | 0.138744 ± 0.007365 | 0.128229 ± 0.002996 | 28.67% | 20.31% |
| H2 | 0.138190 ± 0.007611 | 0.125245 ± 0.002902 | 30.72% | 17.66% |
| H3 | 0.138870 ± 0.007507 | 0.126553 ± 0.002918 | 39.84% | 18.15% |
| H4 | 0.106319 ± 0.005938 | 0.137263 ± 0.003322 | 15.88% | 40.67% |

Every primitive meets reward RMSE <=0.15, successor RMSE <=0.40, and both errors
<=65% of their initial values. Each hallway meets both RMSE limits of 0.25 and
both errors <=50% of initialization. All parameters/metrics are finite, terminal
predictions are zero, and successors remain nonnegative within `1e-7`, with
total discounted mass per source at most gamma+`1e-6` at every checkpoint.

Primitive successor errors settle near 0.35 under constant-step-size stochastic
sampling, unlike the nearly exact deterministic primitive models in Milestone 4.
The contract explicitly allowed for this before training. Passing aggregate
checks does not establish convergence at every state: H1's largest absolute
error in the mean reward prediction is 0.163585 at penalty state `(9,4)`.
The scatter plots show means across runs; the reported RMSE is the mean of
individual models' errors, not the error of an averaged model.

The frozen options have different reward/successor decompositions. At S:

| Option | Exact environment reward | Learned mean reward | Exact discounted target feature | Learned mean target feature |
| --- | ---: | ---: | ---: | ---: |
| H1 | 2.94e-7 | 1.38e-7 | 0.938196 | 0.932794 |
| H2 | -0.005091 | -0.003732 | 0.878169 | 0.877150 |
| H3 | -0.005396 | -0.003814 | 0.747143 | 0.745010 |
| H4 | 0.611332 | 0.612835 | 0.043517 | 0.038242 |

H4's positive reward and small target feature are consistent with its preference
for the main goal from S. The model represents the option actually learned,
rather than forcing hallway attainment or adding an artificial reward.

## Independent rollout audits

Audit each hallway option from S, H1, H2, H3, H4 and penalty state `(9,3)`, with
10,000 rollouts per pair. Seeds 8100–8123 follow option-major order. Sampling uses
the separate Python nine-ticket environment, summing signed discounted rewards
and recording discounted final one-hot features. It never samples from the
oracle's transition table. Compare reward and every successor coordinate with
the corresponding reference using the frozen `0.01 + 6*sample_standard_error`
tolerance.

sample means, standard errors, reference predictions, errors and limits.

## Checkpoint interface and tests

Checkpoints use reward axes `(run, option, input_feature)` and successor axes
`(run, option, output_feature, input_feature)`. Columns index source features.
Each checkpoint records model/feature order, seeds, step count, learning
parameters, gamma, code revision and a SHA-256 link to `frozen_options.json.gz`.
Read them with `json.loads(gzip.decompress(path.read_bytes()))`. Future planning
must verify that policy link before combining an option with its model.

All **212 tests pass**, including 14 added for this milestone. They cover mixed
stochastic outcomes and actions, wall aggregation, fractional stopping,
zero-probability exits, forced first actions, successor orientation, requested
action ratios, separate bootstrap predictions, absence of hallway reward bonuses,
terminal learning before reset, eager/JIT/VMAP agreement, seeded repeatability,
reference identities, artifact validation, per-model acceptance and rollout
discounts. Existing deterministic/two-room model regressions still pass.
The existing PR workflow runs the short suite; full experiments remain separate.
Pre-commit checks pass.
